# GameY

## 🔧 Getting Started

To run this project locally:

### 1. **Clone the repo**

```bash
git clone https://github.com/naomibadelita/GameY.git
cd GameY
```

### 2. **Install dependencies**

Make sure you have NodeJS 24 installed. Then, run the commands
```bash
cd server; npm install; cd ..
cd webapp; npm install; cd ..
cd gameyapi; npm install; cd ..
```

> Make sure all dependencies were installed. If you get an message like `scripts not yet covered by allowScripts`, you will have to review and potentially approve the scripts using `npx npm approve-scripts << The list of packages >>`.


### 3. **Set up the Server**

Run the following command to build the client site, which will be handed to everyone entering the website
```bash
cd gameyapi
npm run build
cd ..
```

**If you're using your computer**

Then, you can run the server with
```bash
cd server
npm run dev
```
And optionally forward your port with Ngrok.
Open a new terminal and run
```bash
ngrok http 8080
```

**If you're using an actual server**

In this case, you will have to forward your port to an internet port, using Nginx. For Ubuntu, this is:
```bash
sudo apt update
sudo apt install -y nginx
sudo nano /etc/nginx/sites-available/gamey
```
* Add the following Nginx configuration, replacing the IP/Domain placeholder
```nginx
server {
    listen 80;
    server_name << Your IP/Domain >>;

    location / {
        proxy_pass http://localhost:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```
* Then run
```
sudo ln -s /etc/nginx/sites-available/gamey /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
sudo ufw allow 'Nginx Full'
```
* If you are connected to your server using SSH, run
```bash
sudo ufw allow ssh
```
* Finish with running
```bash
sudo ufw enable
```

If you are using a server, you probably want the application to start with the server and restart on crash automatically. You can use PM2 for this:
```bash
npm install -g pm2
pm2 install -g tsx
```

> As mentioned above, make sure all dependencies were installed, and that you review and potentially approve all scripts required.

Go inside the `server/` directory and run
```bash
pm2 start --interpreter tsx src/index.ts --name "gamey"
pm2 save
pm2 startup
```
* Run the command generated by `pm2 startup` (`sudo env PATH=`)

**Now the setup is fully done!**

### 4. **Run the app**

Depending on how you set up the server, enter the following URL
* `http://localhost:8080/` - If you're using your computer without ngrok
* `The url provided by ngrok` - If you set up ngrok
* `Your domain` or `Your server's ip:80` - If you set up a server
