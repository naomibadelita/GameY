== Deployment View

Game Y is deployed as a Node.js application. The backend server serves the compiled React webapp, exposes the REST API, and accepts WebSocket connections on the same port. SQLite is stored locally with the backend application.

=== Deployment Overview

[plantuml, deployment-overview, png]
----
@startuml
node "Player Device" {
    artifact "Web Browser" as browser
}

node "Application Server" {
    node "Nginx (optional)" as nginx
    node "Node.js Server\nPort 8080" as server {
        component "Express REST API"
        component "WebSocket Server"
        artifact "React Webapp Build"
    }
    database "SQLite Database" as database
}

browser --> nginx : HTTPS / WSS
nginx --> server : HTTP / WebSocket proxy
server --> database : SQLite queries
@enduml
----

=== Local Development

During local development, the Vite development server runs the React webapp. Requests to `/api` and `/ws` are proxied to the Node.js backend at `http://localhost:8080`.

=== Production Deployment

For production, the React webapp is built and served as static files by the Node.js server on port `8080`. An optional Nginx reverse proxy can expose the application on ports 80 and 443, forward HTTP and WebSocket traffic to the Node.js server, and provide HTTPS. PM2 can be used to keep the Node.js process running and restart it after a failure.

=== Deployment Constraints

* The SQLite database file must be stored on persistent server storage.
* The backend requires a secure `JWT_SECRET` environment variable in production.
* HTTPS should be configured through Nginx before the application is publicly exposed.
